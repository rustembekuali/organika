# Органика — реакцияларды түсініп үйрен

**Сайт:** https://rustembekuali.github.io/organika/

Қазақ тіліндегі органикалық химия реакцияларының интерактивті оқу платформасы (9–11-сынып, ҰБТ, мұғалімдер).

## Не бар

|---|---|
| **Басты бет** | Аты-жөнін енгізу, «Жалғастыр» картасы, 4 негізгі бөлім, видеодағыдай өздігінен ойнайтын реакция анимациясы, күн реакциясы |
| **Үйрену → Тақырыптар** | 24 тақырып × «Алыну жолдары / Химиялық қасиеттері / Сапалық реакциялар / Жиі қателер», іздеу және 7 сүзгі |

| **Үйрену → Негіздер** | Валенттілік, байланыстар, функционалдық топтар, гомологтық қатар, изомерия және номенклатура, реакция түрлері, теңестіру (жану теңдеуін теңестіргіш), генетикалық байланыс, оқу бағыты, бейорганикалық көпір |
| **Тексеру журналы** | Барлық түзетулер мен күмәнді жазбалар, PDF-тің қай бетінен алынғаны |

Прогресс, сақталған реакциялар, қайталау тізімі және қолмен қосылған реакциялар браузерде (`localStorage`) сақталады — тіркелу қажет емес. Оқушы атын енгізеді; «Профиль» бетінде прогресті код немесе файл түрінде басқа құрылғыға көшіруге болады.

Мәзір: **Басты · Үйрену · Карта · Зертхана · Жаттығу** (телефонда — төменгі панель) және оң жақта профиль.

## Жариялау (GitHub Pages)

`main` тармағына push жасалғанда `.github/workflows/deploy.yml` тесттерді іске қосып, сайтты жинайды және `gh-pages` тармағына жариялайды; GitHub Pages сол тармақтан сайтты автоматты түрде жаңартады (1–2 минут). Тесттер өтпесе, сайт жаңартылмайды.

## Іске қосу

Қажет: Node.js 18+ (тексерілгені 22), npm.

```bash
npm install
npm run dev        # әзірлеу сервері: http://localhost:5173
npm test           # деректер мен анимация сахналарының тесттері
npm run build      # dist/index.html — бір файлдағы толық сайт
```

`dist/index.html` файлын кез келген статикалық хостингке салуға немесе браузерде тікелей ашуға болады.

### Құрылымдық формулалар мен анимацияны қайта генерациялау

Заттар немесе реакциялар өзгерсе (Python 3 және RDKit қажет: `pip install rdkit`):

```bash
npm run gen:structures                                   # 2D құрылымдар + формула/SMILES сәйкестігін тексеру
npx tsx scripts/dump.ts scripts/_dump.json && \
python3 scripts/gen_scenes.py scripts/_dump.json src/data/generated/scenes.json   # атомдық анимация сахналары
```

`gen_structures.py` әр заттың формуласы SMILES-пен сәйкес келмесе, қатемен тоқтайды.

## Жаңа реакция қосу

1. Жаңа заттар болса — `src/data/substances.ts`-ке қос (SMILES міндетті емес, бірақ болса құрылым мен анимация шығады).
2. `src/data/reactions/...ts` ішіне жазба қос:

```ts
{
  id: 'propene-hbr', t: 'Пропенге бромсутек қосу', at: ['alkenes:prop', 'halo:get'],
  eq: 'propene + hbr -> bromopropane2', c: 't°', ty: 'add', lv: 'base',
  src: 0, st: 'ok', rule: 'markovnikov',
  b: 'π-байланыс пен H–Br үзіледі; C–H және C–Br түзіледі.',
  x: 'Түсіндірме…', m: 'Жиі қате…', ob: 'Бақыланатын белгі…',
  hl: { propene: 'C=C' },        // құрылымда бөлектеу (SMARTS)
}
```

3. `npm test` — теңдеудің атомдық балансы, сілтемелер, тізбектер автоматты тексеріледі.
4. Құрылымдар мен анимацияны қайта генерациялау (жоғарыдағы командалар).

Зертханадағы «JSON көшіру» батырмасы қолмен қосылған реакцияны осы форматқа жақын түрде береді (`st: 'check'` — тексерілмеген).

Анимациядағы атомдық сәйкестік автоматты түрде (RDKit FMCS) анықталады. Химиялық тұрғыдан бірмәнді емес жағдайларда реакцияға `mp` кеңесі беріледі: `out` (реагенттің суға кететін атомы), `inn` (өнімнің бейорганикалық реагенттен келетін атомы) немесе `pairs` (атомдарды қолмен сәйкестендіру — мысалы, глюкозаның спирттік ашуында видеодағыдай C1/C6 → CH₃, C2/C5 → CH₂OH, C3/C4 → CO₂).

## Дереккөз және тексеру

Негізгі дереккөз: «Химия пәнінен органикалық реакциялардың жинағы» (құраст. Т.Д. Қайратұлы, PDF, 24 бет). Барлық мәтін тексеріліп енгізілді:

- 260 жазба: 233 — жинақтан, 27 — мектеп курсынан қосылды;
- 24 жазба жинақтағы қатемен түзетілді (мысалы: Вюрц реакциясында C₈H₁₆ → C₈H₁₈; циклопропан C₃H₈ → C₃H₆; Коновалов реакциясының шарты — H₂SO₄ емес, сұйытылған HNO₃; бензолсульфон қышқылы C₆H₆SO₃ → C₆H₅SO₃H; дипептидтегі β-аланин құрылымы мен атауы);
- 18 жазба мектептік оңайлатылған жазба ретінде белгіленді;
- 3 жазба күмәнді — ойдан толықтырылмады, жаттығулар мен реакциялар картасына енгізілмеді.

Сыныпқа сәйкестігі көрсетілмеген: ол ресми оқу бағдарламасымен салыстырылмады. Жинақтағы жеке үндеулер мен қаржылай көмек туралы мәтін сайтқа енгізілмеді.
